- `*(Assumed — replace if different)*` - For MOQ, pricing, and policies
- `+91-XXXXXXXXXX` - Replace with actual phone number
- `wholesale@meghdoottextiles.com` - Replace with actual email
- Address details - Replace with actual Bengaluru address

Each page includes JSON-LD schema that should be placed in the `<head>` section:
